# PRD — 이야기 성경 (Story Bible)

> 최종 수정: 2026-07-15

## 1. 제품 비전

지도 위에서 성경 이야기를 인물별로 탐색하며, 퀴즈와 학습 진행 추적을 통해 성경을 체계적으로 공부할 수 있는 인터랙티브 학습 앱.

## 2. 핵심 사용자

| 구분 | 설명 |
|------|------|
| 1차 사용자 | 한국어 성경 공부 초중급자 (개인/소그룹) |
| 2차 사용자 | 교회학교 교사, 성경 스터디 리더 |
| 언어 | 한국어 (KRV 개역한글) |

## 3. 기술 스택

| 영역 | 기술 |
|------|------|
| 프론트엔드 | Flutter (Dart 3.8+), Riverpod 2.6 |
| 백엔드 | Supabase (PostgreSQL + Auth + Storage + RLS) |
| 지도 | MapLibre GL JS WebView + OpenFreeMap Liberty + Mapzen Terrarium DEM |
| AI 에셋 생성 | Google Cloud Vertex AI Imagen |
| 인증 | Apple / Google / Kakao 소셜 로그인 |
| 성경 텍스트 | KRV 개역한글 (31,102절) |

## 4. 핵심 기능

### 4.1 MVP (현재 구현됨)

#### 오늘 홈과 루트 탐색
- 하단 네비게이션은 화면 폭을 채우는 단순한 바 형태로 `오늘` / `성경` / `지도` / `내정보` 4개 탭을 보여 준다.
- `오늘`은 전체 이야기를 `원역사 → 족장 → 출애굽 → 사사 → 통일왕국 → 분열왕국 → 포로 및 포로 후기 → 예수님의 공생애 → 사도 → 후기 사도`와 각 시대 안 사건 순서로 이어 붙인 유한 카드 덱으로 탐색하게 한다. `global_rank`는 이 덱 순서에 사용하지 않는다. 기록이 없으면 원역사의 첫 이야기, 기록이 있으면 가장 최근 감정 새기기 바로 다음 이야기를 현재 추천으로 삼는다. 시대 경계에만 `{시대명}/이동`, 전체 처음·끝에는 `이전/다음 이야기 없음`과 지도 감정 새기기 안내 카드를 표시한다.
- `오늘` 지도에는 현재 이야기와 같은 시대의 모든 사건을 시간순 번호 핀으로 표시한다. 같은 시대의 직전·직후 핀에는 `이전`·`다음` 라벨을 붙이고 현재 핀은 장면 썸네일과 `현재` 배지로 강조한다. 카메라는 같은 시대의 이전·현재·다음만 화면에 차도록 다시 맞춘다.
- `오늘`의 지도는 패널 밖에서 이동·확대·회전할 수 있다. 하단 패널을 조작하는 동안에만 지도 제스처를 막고, `지도` 탭과 같은 3D 지도 상태를 재사용해 탭 전환 때 지형을 다시 로드하지 않는다.
- `오늘` 하단 패널은 지도 탭처럼 고정 헤더 아래 내용을 세로 스크롤하며 화살표로 최소화/최대화한다. 첫 진입에는 이야기 탐험·다이어리·통독과 `내 정보` 확인 방법, 최근 감정 기준 재정렬 방식을 알려 주는 환영 가이드를 띄우고 첫 터치에 닫는다.
- `오늘`의 낮은 퀵 액션에서 오늘 신앙 다이어리 작성/확인과 다음 통독 위치 이어읽기를 제공한다. 오늘의 이야기 감정 새기기, 다이어리, 통독이 각각 미완료이면 해당 카드가 계속 은은하게 빛나고 완료하면 멈춘다. 비로그인 시 `프로필로 이동` 안내로 `내정보` 로그인 화면을 연다.
- 기존 시대·시간순·인물·장소 탐색 홈은 `지도` 탭으로 유지한다.

#### 시대/인물/사건 탐색
- 구약(7시대) / 신약(3시대) — **시대 멀티 선택** 가능 (v2, 숨김 `역사의 종결` 시대 제외)
- 시대 선택 후 **[지역(region) / 인물(character)] 분기 모드** (v2)
  - **지역 모드**: 지도 위 region(영역) 폴리곤 + anchor/minor 점 클릭 → 그 지역의 모든 사건이 시간순 카드 슬라이딩
  - **인물 모드**: 멀티 시대의 인물 풀 → 사건 카드 5열 세로 그리드 + 점선 연결 + 좌우 화살표 prev/next
- 인물별 색상(8색 팔레트) 구분
- 위치 모델 v2: 자유 좌표 대신 region(31개) + anchor(66개) + minor(17개) 카탈로그 + alias_group (모리아산↔예루살렘 성전 등 같은 점 다른 시대 이름 묶음)

#### 인터랙티브 지도
- 사건 위치를 지도 핀으로 표시 (v2: landmark FK 기반). 사용자가 감정을 새긴 사건은 번호 핀 옆 작은 컬러 감정 이모지 배지로 표시된다.
- 시대별 지도 중심/줌 자동 이동
- region 폴리곤 영역 + anchor/minor 점 (v2)
- 핀 클릭 → 이야기 상세 다이얼로그

#### 이야기 상세
- 요약(summary), 4장면 이미지 + 장면별 등장인물
- 성경 구절 참조 (KRV)
- 본문 읽기 + 퀴즈 완료 후 "지도 위에 새기기"로 감정 1개와 100자 메모를 남기면 학습 완료

#### 사용자 기능
- 프로필 관리 (닉네임, 사진, 기도제목)
- 개인 노트 작성/관리
- 성경 구절 북마크
- "진행률 표시" 섹션 — 다이어리로 감정 새김과 오늘의 신앙 기록을 한국 시간 기준 달력으로 표시

#### 기도 공유
- 7자리 공유 코드로 타인의 기도제목 구독
- 중보기도 목록 관리

#### 검색
- 이벤트 전체 텍스트 검색 (디바운스 220ms)
- 제목/요약/본문/장소/인물명 가중치 스코어링

## 5. 데이터 파이프라인 개요

성경 텍스트 → 이야기 JSON → DB 시딩 + AI 이미지 생성의 다단계 파이프라인.
상세는 `docs/DATA_PIPELINE.md` 참조.

```
assets/bible/*.txt ─→ build_krv_seed_sql.py ─→ bible_verses SQL
assets/events/ (각 항목에 story_index 직접 박힘)
                    ├→ build_character_meta_json.py    ─→ character_meta.json (모든 인물 + 아바타 프롬프트)
                    ├→ build_events_seed_sql.py ─→ events SQL (jsonb/배열 흡수)
                    ├→ build_characters_seed_sql.py ─→ characters SQL (is_active 토글 보존)
                    ├→ generate_avatars_vertex.py ─→ 아바타 PNG (기존 보존)
                    └→ generate_event_story_images_vertex.py ─→ 장면 이미지
```

## 7. 접근성

### 색 조합과 글자 크기 조절

고령 사용자의 가독성과 사용자 취향을 위해 앱 전역 색 조합과 글자 크기를 조절할 수 있다. 색 조합은 클래식, 네이비, 파스텔, 다크 4개이며 새 설치 기본값은 네이비다. 글자 크기는 3단계(작게 1.0x / 보통 1.2x / 크게 1.4x)이며 새 설치 기본값은 보통이다.

- **접근**: `오늘` 탭 상단의 `테마`와 `큰글자` 버튼에서 각각 변경
- **UI**: 바텀시트에 색 조합 선택, 글자 크기 미리보기와 3단계 버튼. 선택 즉시 전역 반영.
- **저장**: 기기 로컬(`SharedPreferences`). 앱 재시작 후 복원.
- **범위 외**: OS 시스템 크기 연동, 기기 간 동기화, UI/본문 분리 배율, 서브 페이지 내 글자 크기 버튼.
