# UI 가이드 — 이야기 성경

> 최종 수정: 2026-04-22 (알림/제안/금주 인물 반영)
> 기존 `docs/story_bible_prototype_design.md`의 UX 설계를 기반으로 정리.

## 1. 디자인 철학

- **고지도/양피지 테마**: 성경 시대의 분위기를 시각적으로 전달
- **게임형 UI**: 진행도, XP, 완료 체크 등 게이미피케이션 요소
- **정보 밀도 vs 여백**: 데스크탑은 3열로 정보 밀도 높게, 모바일은 단계적 공개

## 3. 레이아웃

### 3.1 메인 화면 (풀스크린 지도 + 오버레이)

```
┌─────────────────────────────────────────────────────────────┐
│       [🔍] [성경] [미션] [프로필] [글자] [이야기 등록*]       │
│                                                                │
│                  (MapLibre 3D WebView 전체화면)                │
│                                                                │
│   [핀]        [핀]         [핀]                                │
│          [핀]      [핀]                                        │
│                                                                │
│   [이전 단계]                                      [다음]       │
│   ┌─────────────────────────────────────────┐                 │
│   │   [이전 단계]  [시대/방법] > [선택] > [이야기]       │       │
│   │   (3단계 선택 Panel, 드래그로 접기 가능)   │                 │
│   └─────────────────────────────────────────┘                 │
└─────────────────────────────────────────────────────────────┘

*'이야기 등록'은 웹 전용 (kIsWeb 분기).
🔍 = 성경 구절로 이야기 찾기 — 신약/구약, 권, 장 선택 후 절 버튼을 눌러 해당 절이 포함된 이야기 카드를 표시.
📣 = 공지사항과 사용법 — 프로필 헤더에서 개발자가 게시한 안내/가이드를 리스트와 상세 팝업으로 확인한다.
🔔 = NotificationBellButton — 프로필 헤더의 공지 버튼 오른쪽에 있으며, 미독 1개 이상이면 빨간 `!` 배지.
색/글자 = 색 조합과 글자 크기 변경 — 홈 상단 프로필 버튼 오른쪽에서 `FontScaleBottomSheet`를 연다.
```

### 3.3 모바일 시스템 뒤로가기

모바일 홈의 Android 시스템 뒤로가기는 앱 종료보다 먼저 현재 선택 흐름을 한 단계
되감는다. 장소 흐름은 사건 목록 → 지역 선택 → 홈, 인물 흐름은 사건 선택 → 인물
선택 → 홈 순서로 돌아간다. 홈에서 아직 시대가 선택되지 않은 상태에서는 기본
플랫폼 동작대로 앱을 종료할 수 있다.

하단 선택 시트 상단 헤더는 접기/펼치기 버튼과 `시대/방법 → 장소/인물/구간 → 이야기`
라벨형 stepper 만 유지한다. 시스템 뒤로가기와 같은 의미의 이전 액션과 인물/구간
다음 액션은 패널 바로 위 지도 영역에 큰 플로팅 버튼으로만 노출한다. 이전 계열은 좌측
팔레트 액션색 버튼, 다음 계열은 우측 완료색 버튼을 쓰며, 버튼 뒤에는 별도 사각 음영을 두지 않는다.

### 3.4 3D 무료 지도

홈 지도는 OpenFreeMap Liberty style + 공개 Mapzen Terrarium DEM 기반의 무료 3D
지형을 단일 운영 배경으로 사용한다. 별도 API key나 지도 배경 시작값을
받지 않는다. 홈 지도 위에는 별도 확대/축소/출처 컨트롤을 띄우지 않고,
지도 출처와 설명은 프로필 설정 시트의 `지도 설명` 항목에서 확인한다.
3D 지도는 MapLibre GL JS 렌더러로 DEM, pitch, bearing, terrain exaggeration 을
적용한다. Android/iOS 는 네이티브 WebView 로, Flutter Web 은 `HtmlElementView`
iframe 브릿지로 같은 HTML 렌더러를 띄운다. country boundary, region polygon,
사건 경로, hit-zone, 한국어 국가/region 라벨은 GL GeoJSON layer 로 렌더링하고
사건 숫자/감정 핀은 DOM Marker 로 띄워 기본 지도의 영어/현지어 label layer 와
분리한다. 상단/하단 Flutter 오버레이는 유지한다. 지도 HTML 은 renderer 설정이
바뀔 때만 새로 로드하고, 카메라 이동과 시대/지역/사건 선택 변화는 JS `easeTo()`
및 GeoJSON `setData()` 로 갱신해 반복 로딩 overlay 를 피한다.
Android WebView 는 Flutter gesture arena 에서 지도 드래그/핀치를 놓치지 않도록
eager gesture recognizer 를 사용한다. Android 에서는 WebView renderer OOM 을 줄이기
위해 worker/cache/antialias/pitch 를 보수적으로 제한하고 DEM terrain 은 비활성화한다.
또한 WebView 를 Hybrid Composition 으로 생성해 SurfaceProducer/ImageReader 경로의
버퍼 고갈 경고를 줄이고, 화면 전환 때 지도를 내렸다 다시 로드하지 않는다.
네이티브 Activity 는 WebView renderer 종료를 처리해 렌더러가 죽어도 앱 프로세스가
같이 종료되지 않게 한다.
확대/이동 중 일부 타일이나 서브리소스 요청이 실패·취소되어도 지도 실패 팝업이나
반복 로그로 올리지 않는다. 초기 로딩에서 MapLibre `ready` 신호가 일정 시간 오지
않거나 main frame 이 실패한 경우에만 지도 실패 안내와 main-frame 로그를 표시한다.
기본 지도 style 의 symbol label layer 를 숨겨 영어/현지어 지명 대신 앱이 직접
올리는 한국어 국가/region 라벨과 사건 핀만 보이게 한다.
3D 첫 화면은 하단 선택 시트에 사우디아라비아와 걸프 지역이 가려지지 않도록
성경권 경계를 남쪽으로 넓혀 열며, 이집트·아라비아반도·메소포타미아·이란을 함께
확인할 수 있는 저배율 카메라를 기본값으로 쓴다. 서쪽 이동 한계는 이탈리아가
화면 왼쪽에 약간의 여백과 함께 걸리는 정도로 제한해 성경권 밖 서유럽/북아프리카로
과하게 빠지지 않게 한다.
첫 화면과 `시대/방법` 단계로 돌아올 때는 지도 조작 가능성을 암시하도록 약 1초 동안
한 박자 가까운 줌인 3D pitch 상태에서 기본 줌과 정면 pitch 로 빠르게 ease-out 전환한다.
시대 선택 직후 후보 region 경계를 고르는 화면은 카메라 pitch/bearing 을 0으로
전환해 폴리곤이 원근감 때문에 삐뚤어 보이지 않게 한다. 사건·이야기 단계에서는
다시 3D pitch 를 적용해 산맥과 계곡을 읽을 수 있게 한다.
지역을 탭한 직후에는 사건 좌표가 아니라 선택 region polygon 전체를 접힌 하단
시트 기준의 가시 영역에 맞춘다. 사건 핀 reveal 이 끝난 뒤 하단 사건 카드가
올라와 일부 핀을 가릴 수는 있지만, 선택 순간에는 지역 경계가 화면 안에 들어와야
한다. 사건/region 묶음을 맞출 때는 하단 시트 padding 의 큰 일부를 상단
여백에도 나눠 주어, 특히 사도의 시대처럼 북쪽에 긴 사건 흐름과 후보 지역이
상단 오버레이 뒤에 붙지 않고 실제로 눌 수 있는 위치에 내려오게 한다.
3D 지도 위 점선 경로, region polygon, region/국가 라벨, 탭 hit-zone 은 MapLibre
GL GeoJSON layer 로 렌더링하고, 사건 숫자/감정 핀과 non-region 랜드마크는 각각의
GeoJSON point 를 MapLibre DOM Marker 로 투영해 terrain symbol collision 과 무관하게
지도 좌표 위에 고정한다. 인물 선택 이야기 경로는 선택 인물별 GeoJSON line feature 로
분리해 `colorForCharacter` 팔레트 색을 점선에 적용하고, 여러 인물이 같은 구간을
지날 때도 살짝 나란히 보이도록 offset 을 둔다. 랜드마크는 선택된 시대의 non-region
항목만 옅은 투명도로 보이며, 이모지와 이름이 줌 배율에 맞춰 함께 커지거나 작아진다.
region polygon 내부 탭은
`queryRenderedFeatures` 로 fill layer 를 먼저 조회하고, WebView/terrain 상태에서
hit 이 빠질 경우 터치 좌표를 위경도로 바꿔 point-in-polygon 으로 다시 판정한다.
중앙 라벨이 아닌 폴리곤 안쪽을 눌러도 같은 지역 선택으로 처리한다. 사건 0개 region 은
polygon/label/hit layer 에 올리지 않는다. 한국어 국가 라벨은 rounded
rectangle 없이 글자만 쓰고, region 라벨보다 더 짙고 굵은 글자로 읽히게 한다. 국가/region
라벨과 랜드마크 표기는 확대 시 최대 크기에 가까워지고 줌아웃할수록
MapLibre zoom expression 으로 작아져 겹침을 줄인다. 지도 zoom 범위는
성경권 bounds 안에서 더 넓게 조정할 수 있도록 `2.7~12.4` 를 기본 범위로 둔다.
지도 드래그/줌/option-key 조작/MapLibre 컨트롤 조작과 하단 선택 패널 pointer 입력은
tap suppression 을 걸어, 조작 직후 커서 아래 region·랜드마크가 선택되거나
팝업이 뜨지 않게 한다. 하단 선택 패널 pointer 입력 중에는 짧은 gesture suspension 을
갱신해, iOS WebView 계열에서 사건 카드 가로 스크롤이 지도 카메라 pan/zoom 으로
전달되지 않게 한다. 이 gesture suspension 은 pointer up/cancel 때 즉시 해제해
사용자가 곧바로 지도를 움직일 수 있게 한다. 단, 하단 시트가 접힌 상태에서는 보이는
peek/header 영역만 입력을 막고, 위쪽 지도 영역은 즉시 지도 drag/pitch 입력을 받는다.
특히 하단 시트의
뒤로가기/단계 변경 버튼은 시트가 접히며 같은 터치가 WebView 지도 탭으로 이어질 수
있으므로 pointer up/cancel 이후까지 외부 UI 입력으로 취급해 지역 선택 hit-test 와
분리한다.
지역/인물/시간순 reveal 이 긴 경우에는 지도 우측 중앙에 큰 반투명 `>>` 버튼을
띄운다. 이 버튼은 아이콘만 보이고 tooltip 으로 "핀 애니메이션 건너뛰기"를 제공하며,
탭하면 순차 핀 애니메이션을 멈추고 모든 사건 핀을 즉시 표시한 뒤 사건 목록 패널을
펼친다.
지도 안내 오버레이는 설명 캐릭터가 말해주는 채팅형 가이드 말풍선처럼 표현한다.
오버레이 바깥 배경은 현재 팔레트의 상단 버튼 배경색을 반투명하게 따르고, 상단 dismiss
배지는 현재 강조색, 본문 말풍선은 인물 역할색을 이전 역할색 비율에 가깝게 섞어
오렌지/청록 조합이 살아나게 한다. 대신 최종 alpha 를 낮춰 지도 위에 가볍게 얹힌
유리막처럼 보여야 한다. 텍스트와 안내 아이콘은 배경 투명도의 영향을 받지 않도록
완전한 흰색으로 고정한다.
반투명 오버레이 안에서 안내 본문 왼쪽 원형 슬롯에
`assets/avatars_thumbs/guide.png` 를 중앙 기준 1.13배로 살짝 확대해 흰 여백이
도드라지지 않게 담는다. 원형 슬롯 지름은 기본 48px 이고, 홈 첫 안내에서만
70px 로 키워 캐릭터 표정이 더 잘 보이게 한다.
그 오른쪽에는 별도 둥근 말풍선 안에 안내 문장을 배치한다. 상단에는
`화면 아무데나 누르면 사라집니다` 배지를 중앙 정렬로 표시한다. 배지와 안내 본문
사이는 한 줄 정도 더 띄워 말풍선이 답답해 보이지 않게 하고, 본문 문장에는
이모티콘이나 텍스트 그림자를 넣지 않는다. 첫 화면에서도 같은
오버레이로 "오늘은 성경 어디를 여행해볼까요?",
`시간 순·인물·장소` 선택 안내를 보여 주며, 시대 선택 전에는 `①`, `②`
원형 숫자 배지로 단계만 나눠 보여준다. 상단 돋보기 구절 검색 안내는 `②` 아래
번호 없는 괄호 참고 줄로 배치해 번외 동선처럼 보이게 한다. 시대를
고른 뒤에는 안내가 사라지지 않고 선택한 시대의 짧은 설명과 보기 방식 선택 안내로
바뀐다. 첫 화면 제목은 좁은 폰에서도 한 줄을 유지하도록 축소 렌더링하고, 단계
문구는 줄마다 다른 크기로 줄어들지 않도록 같은 본문 크기를 유지한다.
모드 선택 뒤의 region/character/timeline 안내도 같은 캐릭터 가이드 형식으로
통일한다. 안내가 떠 있는 동안 지도·안내문·하단 시트 어디든 pointer down 이
들어오면 안내를 즉시 dismiss 한다. 오버레이가 덮은 지도 영역은 입력을 막지 않고
아래 MapLibre hit-test 로 전달해 첫 탭도 지역 선택이나 일반 지도 탭으로 동작하게
한다. 하단 시트의 버튼/스크롤은 힌트 dismiss 와 기존 동작을 함께 처리한다. 장소
선택 모드로 전환된 직후에는 같은 터치 누수를 막기 위한 짧은 suppression 만 남기고
후속 지역 탭은 빠르게 받을 수 있도록 suppression 을 정리한다.

### 3.5 앱 chrome 톤 색상

3D 지도 배경 자체는 유지하고, 앱 버튼·패널·카드·탭은 선택한 색 조합의 역할색을
따른다. `클래식`은 main 브랜치의 어두운 올리브 chrome, 베이지 패널, 골드 미션을
기준으로 하고, `남색 지도`는 홍보 이미지의 진한 네이비 잉크와 청록 수계 톤을
사용한다. `알록 지도`는 파스텔 보라 primary 와 청록·오렌지·핑크 역할색을 나눠 써서 프로필
탭/카드/통계가 한 색으로 뭉치지 않게 한다. `블랙 지도`는 검은 지도 톤, 어두운
패널, 금빛 포인트를 써서 다크 테마처럼 보이게 한다. 사용자는 `색/글자`
시트에서 이 네 색 조합을 고를 수 있고 선택값은 `SharedPreferences`에 저장된다.
팝업, 홈 선택 시트, 프로필, 퀴즈, 성경 리더, 구절 검색, 알림 드롭다운/전체보기 같은
공통 화면은 `AppPaletteTheme`, `AppColors`, `AppSurfaces`, `SubPageScaffold`,
`ParchmentPageScaffold` 를 통해 같은 팔레트를 공유한다.
본문과 탭 비선택 텍스트는 `palette.text`/`palette.mutedText`를 우선하고,
밝은 고정 표면 위에 다크 팔레트의 밝은 글자를 얹지 않는다. 홈 상단 유틸리티
버튼, 선택 시트 배경/질감/핸들, 시대·인물·구간 선택 카드, 사건 카드, 프로필 요약
카드, 신앙 다이어리/통독 진행률 카드는 `AppPaletteTheme`의 표면·테두리·역할색을
따라 동시에 바뀐다. `블랙 지도`는 카드/패널 표면을 어둡게 유지하고 보조 텍스트를
밝혀, 같은 컴포넌트가 밝은 테마와 다크 테마 모두에서 읽히게 한다. 블랙 팔레트의
프로필 흰색 쉘은 깊은 검정으로 바꾸고, 홈 하단 스크롤 패널은 거의 검정 표면으로
지도와 분리한다. 상세/미션처럼 읽기 중심인 표면은 팔레트 안의 밝은 표면 역할색을
써서 고정 크림색이 반복되지 않게 한다. 블랙 팔레트의
`primary`/`primaryDeep`은 아이콘과 보조 액션에 쓰이는 밝은 청록 계열이며, 구간 선택
패널은 자체 어두운 표면을 깔아 부모 시트 색과 섞이지 않게 한다.
완료 초록과 선택색이 겹쳐 보이지 않도록 사건 카드 선택 테두리는 팔레트 선택색,
완료 테두리는 더 낮은 채도의 초록을 쓴다.

새 홈 선택 패널과 프로필 카드에는 직접 적용하지 않고, `AppPaletteTheme` 표면을
우선한다. 남아 있는 레거시 장식은 점진적으로 팔레트 기반 표면으로 이전한다.
- 패널 배경: 양피지 질감 그래디언트
- 보더: 청록 해안선 계열 또는 골드 강조 테두리
- 그림자: 부드러운 드롭섀도
- 버튼: 청록/네이비 액션, 골드 보조 강조

### 4.3 디자인 시스템 모듈 (`lib/theme/`)

**규칙**:

- 모달·다이얼로그·카드 등 표면은 `AppSurfaces` 팩토리부터 검토.
- 새 값이 정말 필요하면 토큰에 추가한 뒤 참조한다.

### 4.4 Region Polygon — 장소로 보기 3D 지도 표현

장소 선택은 무료 3D 지도 위에서 "성경 세계의 지역을 고르는" 느낌을 유지한다.
후보 region 은 따뜻한 골드 계열, 선택 region 은 세이지 그린 계열로 MapLibre
GeoJSON fill/border layer 에서 직접 그린다. 이전 Flutter `CustomPainter` 기반
2D polygon overlay 는 제거됐고, polygon 시각·라벨·탭 hit-zone 은 모두
`StoryTerrain3dMap` 의 WebView 내부 layer 로 처리한다.

- **후보**: 시대를 켰을 때 사건이 있는 region 만 은은하게 떠오른다.
- **선택**: 특정 region 을 탭하면 선택 색과 라벨 강조로 후보들과 분리된다.
- **Hit-test**: `queryRenderedFeatures` 로 fill layer 를 먼저 조회하고, iOS
  WebView/terrain 조합에서 빠질 경우 화면 좌표를 위경도로 바꿔
  point-in-polygon 으로 다시 판정한다. 장소 선택 단계에서는 region 폴리곤
  hit 을 사건/랜드마크 hit 보다 먼저 처리해 영역 내부 어디를 눌러도 같은
  지역 선택으로 이어지게 한다.
- **라벨**: 장소 선택 단계의 region 라벨은 폴리곤 내부 중심점 근처에
  지도 지명보다 조금 큰 오커/골드 톤 단일 라벨로 표시해 국가명과 구분한다.
  큰 배지나 버튼형 장식 대신 작은 선택 점과 은은한 경계/채움으로 영역 전체가
  선택 가능하다는 affordance 를 준다. 한국어 국가/region 라벨은 기본 지도
  symbol layer 와 분리해 MapLibre expression 으로 줌에 맞춰 크기를 조정한다.
- **사건 핀 우선순위**: 감정이 새겨진 원형핀은 노란 오로라를 상시 표시해
  장소/인물 사건 목록에서도 이미 새긴 이야기가 눈에 띄게 한다. 감정 핀,
  현재 선택 핀, 이전/다음 전환 glow 대상, 감정 도장 대상은 DOM marker
  z-index 를 높여 다른 원형핀과 겹쳐도 숫자나 감정이 가려지지 않게 한다.
- **이전/다음 전환 카메라**: 사건 상세의 이전/다음 이야기 이동은 현재/목표
  핀을 하단 선택 패널 padding 이 반영된 `fitBounds` 로 더 넓게 잡아, 목표
  원형핀이 아래 스크롤 패널 뒤에 숨지 않게 한다. 이때 지도는 잠깐 보여 주는
  전환 애니메이션일 뿐 route history 가 아니므로, 목표 상세의 `<`는 지도
  대신 직전 상세로 돌아가야 한다. 프로필 카드에서 상세로 들어갈 때는 같은
  핀을 약 1초 pulse 로 보여 준 뒤 상세를 열고, 루트 `<`는 프로필로 돌아간다.

## 5. 인터랙션 패턴

### 5.1 시대 → 인물 → 이벤트 흐름

1. 구약/신약 토글 → 해당 시대 목록 표시
2. 시대 탭 선택 → 인물 목록 로드 + 지도 중심 이동
3. 인물 선택 (복수 가능) → 타임라인 병합 표시
4. 이벤트 카드 클릭 → 지도 핀 강조 + 상세 다이얼로그

### 5.2 검색 → 자동 네비게이션

1. 검색어 입력 (220ms 디바운스)
2. 결과 선택 → 시대/인물 자동 선택 + 이벤트 포커스
3. 지도 해당 위치로 이동

### 5.2.1 성경 구절 → 이야기 검색

1. 홈 상단 돋보기 버튼 클릭 → `BibleVerseSearchScreen`
2. 성경 리더와 같은 가로 드롭다운 row 에서 신약/구약, 권, 장 선택 → 해당 장의 절 번호를 프로필 달력처럼 선으로 구분된 버튼 그리드로 표시. 선택된 절의 배경색은 셀 전체를 채우고, 세로 구분선은 오버레이로 그려 선택색과 선이 어긋나지 않게 한다
3. 절 버튼 선택 → 버튼 그리드 바로 아래에 `창 1:1` 같은 짧은 참조 pill 과 선택 구절 본문을 담은 말씀 카드 표시
4. `events_ordered.bible_refs` 범위에 해당 절이 포함된 이야기 검색
5. 결과는 항상 같은 row 에서 왼쪽 70% `StoryMapPanel` 지도와 오른쪽 30% `StoryEventThumbCard` 기반 1열 카드 스크롤 영역으로 표시한다. row 높이는 오른쪽 카드보다 조금 높은 정도로 제한한다.
6. 지도 핀 탭은 해당 이야기 위치를 강조하고, 카드 탭 → 홈의 기존 이야기 상세/본문 읽기/퀴즈/감정 새김 흐름으로 이동

### 5.2.2 매일/주간 미션 카드

1. 홈 상단 **미션** 버튼은 아이콘 없이 텍스트만 표시하고 상단 유틸리티 아이콘 버튼과 같은 높이를 쓴다. 오늘 매일 미션 사건이 이미 완료된 이야기이거나 오늘 KST 감정을 새겼으면 현재 팔레트의 완료색 배경과 흰 글자로 고정하고, 아직 진행하지 않은 사건이면 현재 강조색 배경과 흰 글자 반짝임으로 클릭을 유도한다. 상태 기준은 주간 미션이 아니라 매일 미션이다.
2. 매일 미션은 상단 소개 영역에서 네비게이션 아이콘 + **오늘의 미션** 라벨을 먼저 보여 주고, 그 아래 시대 이모지+텍스트, 인물 avatar+텍스트, 핀 이모지+장소 텍스트로 오늘의 여정을 말한다. 이 소개 문장 안에는 별도 rounded chip 을 쓰지 않는다
3. 매일 미션은 소개 아래 본 미션 블록을 하나의 rounded rectangle 로 묶고, 맨 위에 나침반 이모지 + **오늘의 사건** 라벨을 둔다. 그 아래 "「사건명」 사건" 메인 버튼은 이모지나 선택 라벨 없이 가운데 정렬된 굵은 제목처럼 길게 배치하고, **인물 루트 / 장소 사건**은 `함께 보기` 보조 버튼 row 로 분리한다. 오늘 사건은 항상 핵심 CTA 이고, 인물 루트와 장소 사건은 오늘 사건을 입체적으로 보는 보조 탐색이다. 장소 사건은 1개만 있어도 눌러 볼 수 있으며 사건 수를 그대로 표시한다
4. 매일 미션 본 블록은 버튼 row 아래 지도를 충분히 확보하고, 필요하면 구분선과 사건 카드 row 는 세로 스크롤 아래에서 이어 보여 준다. 인물 루트 지도에서는 인물 코드 legend 를 숨긴다. 같은 사건에 오늘 KST 감정을 새겼으면 축복 문구를, 이전 날짜 감정만 있으면 다시 미션 문구를 구분선과 사건 카드 row 사이에 표시한다. 감정 기록이 없거나 인물/장소 보조 보기에서는 추가 문구를 숨긴다
5. 주간 미션은 인물/지역 헤더와 지도, 사건 카드 row 만 보여 주며 매일 미션 전용 다시 미션/축복 문구를 쓰지 않는다

### 5.3 학습 완료

1. 이야기 상세 → 본문 읽기 + 퀴즈 시작 (4번 보기는 항상 "헷갈렸어요"). 본문 읽기는 사건에 연결된 절만 성경 리더에서 보여 주며, 여러 본문이면 **다음**으로 이동하고 마지막 **읽기 완료** 버튼을 눌러야 완료된다. 뒤로가기(`<`)로 나가면 읽음 처리하지 않는다
2. 각 문항에서 정답 확인 → 즉시 정답/오답/헷갈림 + 해설 표시 → 다음 문항 이동. 마지막 전체 리뷰를 확인하면 정답/오답/헷갈림을 `user_quiz_attempts`에 저장
3. 본문 읽기와 퀴즈가 모두 완료되면 **지도 위에 새기기** 버튼 활성화
4. 감정 8개 중 하나를 고르고 100자 메모를 남기면 `user_event_emotion_marks` 저장
5. 읽기+퀴즈+감정 새김이 모두 끝났을 때 `user_event_progress.is_completed=true` 저장, 도장 문구는 "완료" 대신 선택 감정 심볼. 감정 새김 버튼은 `감정 - 메모`로 표시하고 "완료 취소" 시 감정 row를 삭제해 지도/카드 이모지를 제거한다
6. `notify_quiz_completed` RPC 호출 → 본인 인앱 bell 에 퀴즈 완료 알림 표시
7. 퀴즈 버튼은 `정답 N · 오답 N · 헷갈림 N` 으로 표시하고 정답 0개=빨강, 일부 정답=주황, 모두 정답=초록으로 상태를 보여 준다
8. 지도 번호 핀은 숫자 중심을 유지하고 작은 컬러 감정 이모지 배지를 붙인다. 하단 사건 카드는 감정 새김이 있으면 좌상단 배지를 컬러 감정 이모지로 바꾸고, 우측 하단 작은 초록 원에 이야기 순번을 표시한다
9. 감정 저장 직후 상세 페이지를 잠시 닫아 지도 화면에서 핀/카드 변화를 먼저 보여 주고, 0.5초 뒤 지도 위 해당 사건 핀과 사건 카드에 감정 도장+별가루를 기존 속도로 재생한 다음 도장 완료 후 1초 뒤 같은 상세로 복귀한다. 프로필 나의 다이어리처럼 홈 지도 준비를 건너뛰고 상세에 들어온 경로에서도 저장 직후에는 홈 지도 루트로 돌아가 해당 사건이 표시되도록 준비한 뒤 도장을 재생한다. 지도 위 감정 도장 및 이전/다음 이야기 전환 애니메이션은 내부 재진입 가드로 중복 실행을 막고, 도장 재생 중에는 전체 홈 입력과 시스템 뒤로가기를 잠가 사용자가 애니메이션을 보도록 한다. 이전/다음 이야기 전환으로 잠깐 보이는 지도는 history 가 아니며, 새 상세의 `<`는 직전 상세를 우선 열고 직전 상세가 없으면 원래 진입점으로 돌아간다. 평상시 지도·패널 터치는 차단하지 않는다
10. 프로필 헤더는 `프로필` 제목과 공지/알림/설정 아이콘만 둔다. 진행 본문은 하나의 테두리 없는 순백색 컨테이너로 묶고, 안에 프로필 정보, `이야기 탐험 요약`, `이야기 탐험` 카드 덱, `신앙 다이어리`, `통독 진행률`을 이어 둔다. 안쪽 표면은 위에서 아래로 밝기 위계를 두되 역할색을 섞지 않는다: 프로필 정보는 가장 밝은 중립 표면에 아주 옅은 팔레트 tint 를 얹고, 이야기 묶음은 이야기/액션 주황 계열, 신앙 다이어리는 초록 계열, 통독 진행률은 말씀/primary 계열의 옅은 표면을 쓴다. 프로필 영역에는 `샬롬! 🙌 {닉네임}님`, "오늘도 이야기 탐험, 신앙 다이어리 작성" / "통독으로 하나님과 함께 해보아요!", `할일:` 뒤의 `이야기 탐험`/`신앙 다이어리`/`통독` 체크박스형 오늘 루틴 상태 표시를 둔다. 상태 표시는 버튼이 아니며, 완료 기준(KST 기준 감정 새김 1개 이상, 오늘 신앙 다이어리 작성, 오늘 통독 1장 이상 `read_at`)을 만족하면 체크박스가 초록색 계열로 바뀐다. 할일 row 탭은 프로필 수정이 아니라 완료 기준 안내 팝업을 열고, KST 자정 이후에는 오늘 상태가 다시 비어 보이도록 관련 데이터를 새로고침한다. 요약은 `이야기`, `기록`, `저장`, `말씀` 4col 카드로 구성하고, 각 숫자 뒤 `개` 단위는 숫자보다 작게 표시한다. `이야기`에는 `완료/전체개` 숫자만 두고, 네 카드 색은 현재 팔레트의 `primary`, `currentAccentDeep`, `successBottom`, `primaryDeep` 역할색으로 분산한다. 카드 덱의 메인 카드는 사건 description/summary까지 보여 주도록 세로·가로 여유를 갖고, `다음 이야기` 카드는 오늘 감정 새김 전까지 중심은 거의 투명하고 바깥 edge 가 밝은 노란 gradient/glow 로 깜빡여 내부 정보가 어두워지지 않게 한다. 덱 아래 안내는 `참고` 라벨이 붙은 테두리 없는 가운데 정렬 pill로 표시한다. `탐험 로그` 페이지는 `복습 항목`과 `탐험 달력과 흔적들` 두 묶음이다. 복습 항목의 정답 카드는 비활성화하되 초록색을 유지하고, 세 복습 카드는 아이콘 왼쪽/라벨과 숫자 오른쪽 정렬의 낮은 compact 버튼으로 둔다. 오답/헷갈려요만 선택 가능하며, 같은 카드를 다시 누르면 선택 해제 후 안내 문구로 돌아간다. 오답/헷갈려요 목록은 복습 카드와 같은 컨테이너 안에서 인라인 최대 3줄만 표시하고 더 있으면 `전체 보기` 바텀시트에서 스크롤 목록을 연다. `탐험 달력과 흔적들`은 감정 카테고리 8개 이모지+라벨+개수 버튼, 구분선, 달력, 선택 날짜 기록 순서의 단일 컨테이너다. 감정 카테고리는 필터가 아니라 해당 감정 코멘트 팝업을 연다. 달력 아래에는 별도 구분선 없이 선택 날짜 기록을 표시하며, 감정 코멘트는 신앙 다이어리처럼 rounded card 로 감싼다. 감정 코멘트와 신앙 다이어리가 모두 있으면 감정 코멘트를 먼저, 신앙 다이어리를 아래에 둔다. 둘 다 없으면 "선택한 날짜에 새긴 감정과 코멘트 혹은 신앙 다이어리가 없습니다"를 한 번만 보여 준다. 달력은 프로필 메인이 아니라 `탐험 로그`의 `탐험 달력과 흔적들`으로만 제공한다. `신앙 다이어리` 카드 전체는 전체 일지 목록 진입점이며, 완료 전 `기록하기`와 `이어 읽기`는 테두리 없이 느린 퍼짐 pulse 를 계속 반복하고 완료 후에는 멈춘다. 오늘 작성된 다이어리는 제목과 본문 한 줄 미리보기로 표시하고, 오늘 통독을 완료하면 `이어 읽기` 버튼은 초록색으로 표시한다. 큰 글자 설정에서는 마지막 장 텍스트를 2줄까지 허용한다.
11. `이야기 탐험 요약`의 `저장한 말씀` 카드는 전체 저장 말씀 화면과 같은 `SavedVerseRow` 기반 `SavedVersesScreen`으로 이동한다. 저장한 성경 구절 전체보기와 신앙 다이어리 전체보기는 상단에 아이콘형 이전 버튼과 화면 제목을 같은 row로 배치하고, 본문 카드는 버튼 폭에 밀리지 않도록 좌우 전체 폭을 사용한다
12. `SavedVerseRow`는 왼쪽 본문/코멘트 컬럼과 오른쪽 삭제 아이콘 컬럼으로 구성한다. 왼쪽 첫 줄은 작은 초록 원 참조 배지와 전체 구절 본문을 함께 보여 주고, 저장한 말씀은 아래 구분선 뒤 묵상 코멘트 또는 회색 빈 코멘트 안내를 표시한다. 하이라이트만 지정한 말씀은 코멘트 영역을 숨기고 row 배경을 선택한 파랑/노랑 형광색으로 칠한다
13. 프로필 "다이어리" 탭은 기존 지도형 장식을 쓰지 않고 한국 시간 기준 달력으로 감정 기록을 보여 준다. 접힌 상태에서는 오늘이 포함된 주와 그 전 주, 총 2주(일~토)를 보여 주고, 펼치면 월 전체와 이전/다음 월 이동을 제공한다. 날짜 셀은 얇은 구분선만 사용하고 오늘은 날짜 숫자 동그라미, 선택 날짜는 은은한 배경으로 구분한다. 프로필 진행 섹션에서는 `신앙 다이어리`와 `통독 진행률` 카드가 달력보다 먼저 나오며, 독립 다이어리 위젯은 달력 아래 배치도 지원한다. 모든 일지는 `전체 보기`에서 날짜가 포함된 카드 목록으로 확인한다. 오늘의 감정 row 목록은 다이어리 아래 탭이 아니라 `이야기 탐험` 통계 col 의 감정 팝업으로 이동한다.
14. 게이미피케이션(score/xp) 없음 — 완료 플래그만 기록 (ADR 참조)

### 5.4 비로그인 로그인 유도

1. 사용자별 저장이 필요한 액션은 비로그인 상태에서 즉시 3초 스낵바를 띄우고 우측에 **이동** 액션을 둔다. **이동**은 프로필 탭의 인라인 로그인 카드로 진입한다.
2. 인라인 로그인 카드는 카카오/Google/Apple 소셜 로그인만 제공한다. 모바일 OAuth는 앱 바깥 기본 브라우저가 아니라 인앱 브라우저/Safari View Controller 계열 launch mode를 사용한다. Google 재로그인은 이전 계정으로 바로 들어가지 않도록 계정 선택 화면을 요청한다.
3. 적용 대상: 사건 상세 **퀴즈 시작**, 성경 구절 저장/하이라이트, 성경 화면 우측 상단 저장 말씀 버튼, 사건 읽기 완료 저장, 이야기 저장, 감정 새김.
4. 성경 읽기 자체와 매일/주간 미션 목록은 비로그인도 열 수 있지만, 마지막 **읽기 완료**나 퀴즈 결과 저장처럼 사용자별 진행도 저장을 시도하면 로그인 유도로 돌아간다.

### 5.5 알림 (Bell)

1. 프로필 헤더의 🔔 아이콘 클릭 → 드롭다운 오픈 (미독 최대 5개)
2. 알림 탭 → `mark_notification_read` RPC + deep link 라우팅
   (`/proposal/<id>`, `/event/<id>`, `/weekly` 중 하나)
3. 모바일/태블릿에서 제안 관련 알림 탭 → "컴퓨터에서 확인하세요" 다이얼로그
4. "모두 읽음" → count/list/history provider 를 함께 invalidate 해 빨간 `!` 배지와 "새로운 알림이 없어요" 빈 상태를 즉시 반영
5. "전체 보기" → `NotificationHistoryScreen` (최근 30일, 읽은 것 포함)

### 5.6 공지사항과 사용법

1. 프로필 헤더의 📣 아이콘 클릭 → `AppPublicationsScreen`.
2. 게시물은 프로필 신앙 다이어리 전체보기처럼 제목과 본문 일부가 보이는 리스트로 표시한다.
3. 항목 탭 → `ParchmentDialog` 상세 팝업에서 전체 본문을 보여 주고, 본문 URL 줄 또는 `link_url`은 자동 링크 줄로 렌더링한다.
4. URL 줄은 `url_launcher`로 브라우저를 열어 개발자가 게시한 가이드 문서로 이동한다. 별도 링크 액션 버튼은 두지 않는다.

## 6. 접근성

### 글자 크기와 지도 설명

홈 상단의 `색/글자` 버튼을 누르면 바텀시트가 열리며 색 조합 3개를 1행 3열 버튼으로 보여 준다. 이 바텀시트가 떠 있는 동안은 아래 지도 tap/gesture 를 잠가 색상 버튼 탭이나 시트 스크롤이 지도 region/landmark 팝업이나 카메라 이동으로 전달되지 않게 한다. `글자 크기` 제목 아래에는 미리보기 문구("태초에 하나님이 천지를 창조하시니라 (창세기 1:1)")를 먼저 표시하고, 그 아래에 글자 크기 3단계(보통 1.0x / 크게 1.2x / 아주크게 1.4x)를 둔다. 각 색 조합은 실제 앱에서 쓰이는 주요 색을 하나의 원형 4분할 미리보기로 보여 준다. 선택 즉시 색 조합은 전역 `ThemeData`와 공통 버튼/카드 색에, 글자 크기는 `MediaQuery.textScaler`에 반영되며 둘 다 `SharedPreferences`에 저장된다. `아주크게`에서는 홈 보기 방식 버튼을 1행 3열로 유지한 채 카드 높이를 늘리고, 카드형 UI는 텍스트 배율에 맞춘 높이와 scaleDown 메타 row 로 overflow 를 막는다. 버튼 라벨, 이야기 제목, 카드 설명, 장면 캡션처럼 사용자가 읽어야 하는 핵심 텍스트는 `TextOverflow.ellipsis`로 숨기지 않고 줄바꿈, 가변 높이, 또는 카드 내부 스크롤로 끝까지 읽을 수 있게 한다. 프로필 설정 시트의 `지도 설명`은 운영 지도 배경의 출처와 라이선스를 `ParchmentDialog`로 보여 준다.
