# UI 가이드 — 이야기 성경

> 최종 수정: 2026-08-12 (추천 여정·범위 라디오·중첩 시대 선택)
> 기존 `docs/story_bible_prototype_design.md`의 UX 설계를 기반으로 정리.

## 1. 디자인 철학

- **고지도/양피지 테마**: 성경 시대의 분위기를 시각적으로 전달
- **게임형 UI**: 진행도, XP, 완료 체크 등 게이미피케이션 요소
- **정보 밀도 vs 여백**: 데스크탑은 3열로 정보 밀도 높게, 모바일은 단계적 공개

## 3. 레이아웃

### 3.1 메인 화면 (`오늘` + 루트 네비게이션)

```
┌──────────────────────────────────────────────┐
│ 샬롬 👋 사용자님,       [찾기] [큰글자] [테마]  │
│ 오늘도 주님과 함께 걸어볼까요!                  │
│       [연속][탐험][다이어리][통독]  ← 지도 위   │
│     (현재 시대 전체 번호 핀 + 현재 썸네일)       │
│ ┌──────────────────────────────────────────┐ │
│ │ 이전(절반)     [현재 카드]     다음(절반)       │ │
│ │        낮은 가로형 썸네일 + 2줄 요약          │ │
│ └──────────────────────────────────────────┘ │
│       [오늘]   [성경]   [지도]   [내정보]       │
└──────────────────────────────────────────────┘

`지도` 탭은 기존 시대·시간순·인물·장소 선택 지도다. 돋보기·성경·프로필·색/글자는 제거하고 `미션`과 웹 전용 `이야기 등록`만 유지한다. 지도 탭 진입과 이탈 양쪽에서 시대·방법·사건을 초기화해 `오늘`의 현재 시대를 물려받지 않고 매번 시대/방법 선택부터 시작한다. 시대를 선택한 직후 지도 가이드는 그 시대 사건의 실제 성경 참조에서 권 이름을 모아 정경 순서로 나열한다. 본문의 핵심 정보는 `시대명 - 권 이름 목록`과 `선택된 시대를 보는 방법을 선택하세요` 두 불릿으로 표시한다. 그 아래에는 괄호 없이 가운데 정렬한 `다른 시대를 선택하려면` 제목과 `시대 다시 선택`·`또는`·`시대/방법` 액션 pill을 두며, 위의 두 불릿보다 한 단계 작은 글자로 정보 위계를 구분한다.
찾기 = `오늘` 탭에서 성경 구절로 이야기 찾기. 헤더 유틸리티 버튼은 40px로 낮추고 아이콘은 17px로 맞추며, 현재 팔레트의 내비게이션 표면에 `primary`를 옅게 섞은 배경과 `primaryDeep` 전경색을 사용한다.
📣 = 공지사항과 사용법 — 프로필 헤더에서 개발자가 게시한 안내/가이드를 리스트와 상세 팝업으로 확인한다.
🔔 = NotificationBellButton — 프로필 헤더의 공지 버튼 오른쪽에 있으며, 미독 1개 이상이면 빨간 `!` 배지.
큰글자/테마 = `오늘` 탭에서 각 설정 섹션만 담은 `FontScaleBottomSheet`를 연다.
지도 가이드의 `화면 아무데나 누르면 사라집니다` 배지는 바깥 프레임의 상단 중앙 경계에서 조금 더 위로 올려 얕게 겹친다. 기본 가이드는 아바타와 말풍선 row 및 프레임 아래쪽 위치를 유지하고 프레임 위쪽 여백만 12px로 늘린다. 시대 선택 직후 정보 가이드는 얼굴 PNG와 원형 슬롯·간격을 제거하고 말풍선을 그 공간까지 넓힌다. 이 가이드의 다른 시대 안내는 괄호와 따옴표 문장 대신 가운데 정렬된 `다른 시대를 선택하려면` 제목과 `시대 다시 선택`·`또는`·`시대/방법` 액션 pill row로 분리하며, 제목과 pill 글자는 위의 선택 시대·방법 안내보다 한 단계 작게 둔다. 작게·보통·크게에서는 pill 단위로 자연스럽게 줄바꿈한다. 오늘 탭의 비로그인 사용법 가이드는 캐릭터 형식을 사용하지 않고 테마별 안내 컨테이너로 구분하되, 같은 `MapHintDismissBadge`를 컨테이너 상단에 공유한다. 안내 본문은 팔레트의 `primaryDeep`을 유지하면서 현재 이야기 카드 제목과 같은 `titleSmall` 기반 w700 글자를 쓰되 크기는 상단 닫기 안내와 같은 11.5px로 두고, `currentAccentDeep` 원형 윤곽 안의 숫자 `1`·`2`로 카드 가로 스크롤과 상단 여정 변경 단계를 구분한다.
`다크` 색 조합 미리보기는 검은 지도 표면과 어두운 카드색을 우선 보여 주어 실제 다크 화면과 인상이 맞아야 한다.
`오늘` 이야기 덱은 하단 스크롤 패널이나 접기 핸들 안에 넣지 않고 지도 위에 직접 띄운다. 가운데 카드는 기존보다 약 1.2배 넓히고, 이전·다음 표면은 화면에 약 절반만 보이면서 가운데 높이의 60%가 되도록 배치해 가운데 선택을 강조한다. 인접 카드를 누르면 상세를 열지 않고 먼저 가운데로 이동하며, 가운데 카드 본문이나 `지금 이어보기` CTA를 누르면 상세로 진입한다. 세 카드 외곽선은 1px이다. 가운데 카드에는 별도 `이어볼 이야기` 상태 라벨과 인물 pill을 두지 않고 제목 → 지역·연대 → 썸네일 → 최대 2줄 요약 → 주황색 CTA 순서로 배치한다. 지도·검색·복습 등 다른 화면의 공용 카드 인물 표시는 유지한다. 썸네일은 카드보다 좌우 폭이 좁고 높이가 폭의 70%인 낮은 가로형이다. 카드 높이는 CTA가 아래에서 잘리지 않도록 확보하며 이전·다음도 같은 60% 비율로 함께 늘린다. 작게·보통에서는 내부 세로 스크롤 없이 CTA를 카드 하단에 고정해 한눈에 보이게 하고, 크게에서만 긴 내용을 위한 내부 스크롤을 허용한다. 현재 제목은 한 줄 폭을 넘을 때 자동 이동하고 이전·다음 제목은 한 줄 말줄임표를 쓴다. 감정 새김은 완료 상태와 현재 카드 위치만 갱신하며 카드 시간순을 재정렬하지 않는다. 선택 범위의 첫·마지막 가상 카드는 범위명을 포함한 안내를 보여 준다. 작게·보통·크게 모두 가로/세로 overflow를 막고, 오늘 화면에는 다이어리/통독 퀵 액션을 두지 않는다.
`오늘` 헤더는 상태바 안전영역까지 이어지고 하단 루트 네비게이션과 같은 팔레트 표면색을 사용한다. 헤더 바로 아래 여정 진입점은 중첩된 큰 pill을 피하고 20px radius의 옅은 카드 표면으로 고정한다. 첫 줄에는 34px 톤형 route 아이콘과 `여정 선택 · 현재 조건명`을 한 줄 정보로 두고 오른쪽 끝에 30px 원형 chevron을 배치한다. 둘째 줄에는 작은 `진행률` label과 높이 14px의 progress track을 두며 `완료/전체` 수는 bar 정중앙에 겹쳐 표시한다. 트랙은 팔레트별 `currentFill`과 강조색 테두리를 사용해 네이비의 0% 상태에서도 윤곽이 보여야 한다. 숫자는 bar 밖 별도 열에 두지 않는다. 카탈로그를 불러오는 동안에는 `0/0`과 빈 여정 문구를 노출하지 않고 indeterminate progress와 `불러오는 중`, 이야기 덱의 로딩 표시를 사용한다. 선택 바는 `전체 순서`, `일부 구간`, `{권/인물} 이야기만`, `{권/인물} · 시대 구간`을 표시한다. 로그인 사용자는 별도 사용법 오버레이를 보지 않는다. 비로그인 사용자에게만 `1. 아래 이야기 카드를 옆으로 스크롤 하거나 눌러보세요`, `2. 화면 위 '여정 선택'에서 아래 나열될 이야기 카드를 변경해보세요` 안내를 번호 원형과 함께 팔레트 프레임에 표시하고, 지도 탭과 같은 `화면 아무데나 누르면 사라집니다` 배지를 위에 겹친다. 첫 터치는 안내만 닫고 지도·카드 동작으로 전달하지 않는다.

여정 선택 첫 화면은 `어떤 기준으로 이야기를 따라가 볼까요?` 질문 아래에 `성경 전체를 순서대로`·`인물에서 시작하기`·`성경책에서 시작하기`·`시대·구간에서 고르기` 순으로 아이콘·제목·설명이 있는 같은 크기의 한 열 카드를 배치한다. 별도 `원하는 곳에서 시작하기` 문구는 두지 않는다. 전체 순서가 실제 선택된 동안만 단색 route 아이콘, 보라 그라데이션과 초록 체크를 표시하고 `추천` pill은 숨긴다. 다른 여정이 선택됐을 때는 중립 표면과 `추천` pill을 보여 추천과 현재 선택을 혼동하지 않게 한다. 선택된 시작 방법 카드는 같은 보라 그라데이션·흰 글자·초록 체크를 사용해 어느 방식이 현재 상태인지 즉시 보이게 한다. 어떤 카드에도 말줄임표를 쓰지 않는다. `전체 순서`는 `전체 순서로 설정하시겠습니까?` 확인 뒤 적용한다. 시작 방법과 현재 정보 사이에는 단색 route 아이콘을 둔 가로 구분선을 넣는다. 별도 `선택된 이야기 정보` 제목은 두지 않고, 단색 route 아이콘이 있는 `현재 선택된 여정` 패널에 방식과 선택 범위를 표시한다. 세부 범위는 수동 개행 없이 `시대 | 대분류(소분류, 소분류)` 형식으로 묶고, 권·인물 여정은 대상 이름을 앞에 붙인 한 문자열로 이어 써 화면 폭에서만 자연스럽게 줄을 바꾼다. progress bar 중앙에는 `완료/전체` 숫자만 표시하며 뒤에 `완료`라는 글자는 붙이지 않는다. 패널 탭은 전체 포함 수 팝업 또는 저장된 일부 구간/권/인물의 마지막 선택 페이지로 이동하고 기존 라디오·체크·펼침 상태를 복원한다. 하단 주 CTA는 `선택된 여정으로 지도 위 나열`을 사용한다. 성경책·인물 검색창은 비어 있을 때 구약·신약 선택을 따르되 검색 중에는 성약 필터를 무시하고 전체 결과를 즉시 보여 준다.

`선택된 이야기 정보`는 선택 카드와 구분되도록 체크 아이콘·외곽 테두리·그림자를 쓰지 않고, 옅은 정보 표면과 세로 강조선만 둔다. 내용은 선택 방식 → `선택 구간 · 실제 소분류 목록` → 완료/전체 수 순서다. 실제 소분류 줄은 시대 범위 선택일 때만 표시하고 말줄임표 없이 줄바꿈한다.

여정 선택과 하위 화면은 배경이 있는 텍스트형 이전 버튼과 제목 pill을 쓰지 않는다. `<` 모양의 chevron 아이콘과 장식 없는 페이지 제목을 같은 헤더에 둔다. 시대·구간 페이지 헤더는 첫 화면의 진입명과 같은 `시대·구간에서 고르기`를 사용하고, 별도 제목·설명·`N개 구간 선택` 진행 요약 없이 구약·신약 필터와 시대 목록부터 시작한다. 필터를 전환해도 반대 성약에서 이미 고른 소분류는 유지한다. 시대 목록은 시대별 외곽 카드를 반복하지 않고 하나의 공용 컨테이너 안에 구분선으로 나열한다. 시대는 복수 선택 체크박스를 유지하며 처음 모두 접고, 일부 소분류만 저장된 시대만 복원 시 펼친다. 시대 전체 체크박스를 선택하면 모든 소분류를 체크하고 해당 소분류 묶음을 자동으로 펼쳐 결과를 바로 보여 준다. 시대 코드에 따른 이모지(빛·가족·피라미드·땅·왕관·분열·사슬·십자가·배·편지)는 별도 열을 만들지 않고 쉬운 시대 제목·DB 시대명과 같은 제목 줄 안에 둔다. 긴 제목·시대명 조합은 한 줄 가로 수동 스크롤과 오른쪽 fade로 끝까지 확인한다. 그 아래에는 실제 사건에 연결된 성경 권 전체를 정경 순으로 한 줄 가로 스크롤한다. 펼친 소분류 묶음은 선택한 시대 행 아래에서 좌우 폭을 줄인 별도 표면과 테두리로 감싸 계층을 드러내고, 소분류는 체크박스와 제목을 한 줄에 둔다. `선택한 N개 이야기로 시작` CTA를 화면 아래 floating 버튼으로 고정한다.

성경책·인물 목록은 헤더 아래 소개 제목과 설명을 생략하고 페이지 제목을 각각 `성경책에서 시작하기`·`인물에서 시작하기`로 통일한다. 구약·신약 segmented control 위에는 역할색 포커스 테두리를 가진 검색창을 두고, 한 글자씩 입력할 때마다 현재 성약의 목록을 즉시 필터링한다. 결과가 없으면 같은 표면 안에 빈 상태를 표시한다. 구약·신약 segmented control은 선택 표면에 흰 글자(다크 테마에서도 대비되는 강조 글자)를 사용한다. 성경책은 66권을 모두 보여 주되 연결 이야기가 없는 권은 `0개`와 중립 회색 표면·테두리·글자로 비활성화한다. 요한계시록은 공개 전이므로 항상 이 상태다. 인물은 같은 줄의 구약·신약 segmented control과 단일 정렬 dropdown(`시간순`/`가나다순`)을 사용한다. 모든 인물은 하나의 공용 표면 안에 5열로 표시하고 항목별 사각 컨테이너는 두지 않는다. 아바타는 셀 폭이 허용하는 범위에서 기존의 약 2.2배까지 키우고, 원 주위 완료 도넛과 상단 `완료/전체` 분수, 하단 이름 overlay를 사용한다. 권·인물의 `읽을 범위 선택`은 상단의 대상·포함 시대를 비입력 정보 표면으로 보여 주고, 그 아래 `읽을 범위를 하나 선택해 주세요`와 실제 선택 카드를 분리한다. `아래 두 방법…` 보조 문구는 두지 않는다. 선택 순서는 `대상 이야기만` → `대상이 속한 시대 선택`이고 단일 방식 선택은 체크박스가 아니라 원형 라디오 표시를 쓴다. 진입 시 `대상 이야기만`이 기본 선택되며 시대 선택은 접혀 있다. 시대 선택 카드를 누르면 라디오와 목록을 펼치되 어떤 시대·소분류도 자동 체크하지 않는다. 목록 안의 모든 대분류와 소분류는 처음부터 펼친 상태로 보여 준다. 대분류/소분류 체크박스로 복수 선택하며 각 소분류 오른쪽에는 `완료/전체` 숫자 분수를 둔다. 실제 대상 이야기가 있는 곳에는 `characterAccent` 대비 배경·테두리·그림자를 가진 badge를 붙여 모든 테마에서 중첩 표면과 구분한다.
`내정보`의 `다이어리`·`통독 진행률` 요약 카드는 각각 하단에 `기록하기`·`이어읽기` 액션을 둔다. 다이어리 액션은 오늘 기록이 없으면 새 기록을, 있으면 해당 기록 수정을 열고 통독 액션은 아직 완료하지 않은 다음 장을 연다. 두 버튼은 채움 원과 반복 glow 대신 옅은 색면·얇은 외곽선·둥근 사각형 아이콘으로 가볍게 표현하고, 안내 문구/도넛과 버튼 사이의 불필요한 빈 공간을 최소화한다. `크게` 글자와 좁은 화면에서는 아이콘과 라벨을 폭에 맞춰 한 줄로 축소해 overflow를 막고, 카드는 내용과 액션 높이에 맞춰 늘어난다.
```

### 3.3 모바일 시스템 뒤로가기

모바일 홈의 Android 시스템 뒤로가기는 앱 종료보다 먼저 현재 선택 흐름을 한 단계
되감는다. 장소 흐름은 사건 목록 → 지역 선택 → 홈, 인물 흐름은 사건 선택 → 인물
선택 → 홈 순서로 돌아간다. 홈에서 아직 시대가 선택되지 않은 상태에서는 기본
플랫폼 동작대로 앱을 종료할 수 있다.

하단 선택 시트 상단 헤더는 접기/펼치기 버튼과 `시대/방법 → 장소/인물/구간 → 이야기`
라벨형 stepper 만 유지한다. 시스템 뒤로가기와 같은 의미의 이전 액션과 인물/구간
다음 액션은 패널 바로 위 지도 영역에 큰 플로팅 버튼으로만 노출한다. 이전 계열은 좌측
팔레트 액션색 버튼, 다음 계열은 우측 완료색 버튼을 쓰며, 버튼 뒤에는 별도 사각 음영을 두지 않는다.

### 3.4 3D 무료 지도

홈 지도는 OpenFreeMap Liberty style + 공개 Mapzen Terrarium DEM 기반의 무료 3D
지형을 단일 운영 배경으로 사용한다. 별도 API key나 지도 배경 시작값을
받지 않는다. 홈 지도 위에는 별도 확대/축소/출처 컨트롤을 띄우지 않고,
지도 출처와 설명은 프로필 설정 시트의 `지도 설명` 항목에서 확인하며, 팝업은 현재 팔레트 표면과 텍스트색을 따른다.
3D 지도는 MapLibre GL JS 렌더러로 DEM, pitch, bearing, terrain exaggeration 을
적용한다. Android/iOS 는 네이티브 WebView 로, Flutter Web 은 `HtmlElementView`
iframe 브릿지로 같은 HTML 렌더러를 띄운다. country boundary, region polygon,
사건 경로, hit-zone, 한국어 국가/region 라벨은 GL GeoJSON layer 로 렌더링하고
사건 숫자/감정 핀은 DOM Marker 로 띄워 기본 지도의 영어/현지어 label layer 와
분리한다. 상단/하단 Flutter 오버레이는 유지한다. 지도 HTML 은 renderer 설정이
바뀔 때만 새로 로드하고, 카메라 이동과 시대/지역/사건 선택 변화는 JS `easeTo()`
및 GeoJSON `setData()` 로 갱신해 반복 로딩 overlay 를 피한다.
루트 탭 전환, 앱 resume, 회전/창 크기 변경 뒤에는 보존 중인 같은 WebView와
MapLibre 인스턴스에 `resize()`와 repaint만 요청한다. `ResizeObserver`도 실제 지도
컨테이너 크기 변화를 감지하므로 탭을 돌아다녀도 style/타일을 처음부터 다시 받지 않는다.
Android WebView 는 Flutter gesture arena 에서 지도 드래그/핀치를 놓치지 않도록
eager gesture recognizer 를 사용한다. Android 에서는 WebView renderer OOM 을 줄이기
위해 worker/cache/antialias/pitch 를 보수적으로 제한하고 DEM terrain 은 비활성화한다.
또한 WebView 를 Hybrid Composition 으로 생성해 SurfaceProducer/ImageReader 경로의
버퍼 고갈 경고를 줄이고, 화면 전환 때 지도를 내렸다 다시 로드하지 않는다.
네이티브 Activity 는 WebView renderer 종료를 처리해 렌더러가 죽어도 앱 프로세스가
같이 종료되지 않게 한다.
확대/이동 중 일부 타일이나 서브리소스 요청이 실패·취소되어도 지도 실패 팝업이나
반복 로그로 올리지 않는다. 최초 style 로드와 캔버스 크기가 모두 정상인 경우에만
MapLibre `ready`로 인정한다. 준비 중에는 움직이는 원형 진행 표시와
`3D 지도를 불러오는 중이에요` 문구를 계속 보여 준다. 초기 로딩이 5초 안에
준비되지 않거나 main frame/JS가 실패하면 자동 재생성 없이 `다시 시도`가 있는 실패
안내를 바로 표시한다. 사용자가 다시 시도하면 WebView/iframe 자체를 새로 만들고,
이전 로딩 세션의 늦은 메시지는 현재 세션에 반영하지 않는다. 재시도도 5초 안에
준비되지 않으면 버튼을 숨기고 `앱을 완전히 종료한 뒤 다시 실행해 주세요.`를 표시하며,
운영 Crashlytics에 개인 정보 없는 non-fatal 1건만 기록한다.
기본 지도 style 의 symbol label layer 를 숨겨 영어/현지어 지명 대신 앱이 직접
올리는 한국어 국가/region 라벨과 사건 핀만 보이게 한다.
3D 첫 화면은 하단 선택 시트에 사우디아라비아와 걸프 지역이 가려지지 않도록
성경권 경계를 남쪽으로 넓혀 열며, 이집트·아라비아반도·메소포타미아·이란을 함께
확인할 수 있는 저배율 카메라를 기본값으로 쓴다. 서쪽 이동 한계는 이탈리아가
화면 왼쪽에 약간의 여백과 함께 걸리는 정도로 제한해 성경권 밖 서유럽/북아프리카로
과하게 빠지지 않게 한다.
첫 화면과 `시대/방법` 단계로 돌아올 때는 지도 조작 가능성을 암시하도록 약 1초 동안
한 박자 가까운 줌인 3D pitch 상태에서 기본 줌과 정면 pitch 로 빠르게 ease-out 전환한다.
시대 선택 직후 후보 region 경계를 고르는 화면은 카메라 pitch/bearing 을 0으로
전환해 폴리곤이 원근감 때문에 삐뚤어 보이지 않게 한다. 사건·이야기 단계에서는
다시 3D pitch 를 적용해 산맥과 계곡을 읽을 수 있게 한다.
지역을 탭한 직후에는 사건 좌표가 아니라 선택 region polygon 전체를 접힌 하단
시트 기준의 가시 영역에 맞춘다. 사건 핀 reveal 이 끝난 뒤 하단 사건 카드가
올라와 일부 핀을 가릴 수는 있지만, 선택 순간에는 지역 경계가 화면 안에 들어와야
한다. 사건/region 묶음을 맞출 때는 하단 시트 padding 의 큰 일부를 상단
여백에도 나눠 주어, 특히 사도의 시대처럼 북쪽에 긴 사건 흐름과 후보 지역이
상단 오버레이 뒤에 붙지 않고 실제로 눌 수 있는 위치에 내려오게 한다.
3D 지도 위 점선 경로, region polygon, region/국가 라벨, 탭 hit-zone 은 MapLibre
GL GeoJSON layer 로 렌더링하고, 사건 숫자/감정 핀과 non-region 랜드마크는 각각의
GeoJSON point 를 MapLibre DOM Marker 로 투영해 terrain symbol collision 과 무관하게
지도 좌표 위에 고정한다. 인물 선택 이야기 경로는 선택 인물별 GeoJSON line feature 로
분리해 `colorForCharacter` 팔레트 색을 점선에 적용하고, 여러 인물이 같은 구간을
지날 때도 살짝 나란히 보이도록 offset 을 둔다. 랜드마크는 선택된 시대의 non-region
항목만 옅은 투명도로 보이며, 이모지와 이름이 줌 배율에 맞춰 함께 커지거나 작아진다.
`오늘` 지도도 현재 시대 사건 사이의 시간순 점선을 항상 표시한다. 카메라 bounds는
전체 시대 핀이 아니라 같은 시대의 `이전·현재·다음` 역할 핀만 사용하고, 가까운
세 좌표에는 최대 9.0 줌을 허용해 역할 핀이 가시 지도 영역을 채우게 한다.
완료 사건은 지도 탭과 똑같이 감정을 핀 중앙에 두고 이야기 번호를 우측 아래에 표시한다.
region polygon 내부 탭은
`queryRenderedFeatures` 로 fill layer 를 먼저 조회하고, WebView/terrain 상태에서
hit 이 빠질 경우 터치 좌표를 위경도로 바꿔 point-in-polygon 으로 다시 판정한다.
중앙 라벨이 아닌 폴리곤 안쪽을 눌러도 같은 지역 선택으로 처리한다. 사건 0개 region 은
polygon/label/hit layer 에 올리지 않는다. 한국어 국가 라벨은 rounded
rectangle 없이 글자만 쓰고, region 라벨보다 더 짙고 굵은 글자로 읽히게 한다. 국가/region
라벨과 랜드마크 표기는 확대 시 최대 크기에 가까워지고 줌아웃할수록
MapLibre zoom expression 으로 작아져 겹침을 줄인다. 지도 zoom 범위는
성경권 bounds 안에서 더 넓게 조정할 수 있도록 `2.7~12.4` 를 기본 범위로 둔다.
지도 드래그/줌/option-key 조작/MapLibre 컨트롤 조작과 하단 선택 패널 pointer 입력은
tap suppression 을 걸어, 조작 직후 커서 아래 region·랜드마크가 선택되거나
팝업이 뜨지 않게 한다. 하단 선택 패널 pointer 입력 중에는 짧은 gesture suspension 을
갱신해, iOS WebView 계열에서 사건 카드 가로 스크롤이 지도 카메라 pan/zoom 으로
전달되지 않게 한다. 이 gesture suspension 은 pointer up/cancel 때 즉시 해제해
사용자가 곧바로 지도를 움직일 수 있게 한다. 단, 하단 시트가 접힌 상태에서는 보이는
peek/header 영역만 입력을 막고, 위쪽 지도 영역은 즉시 지도 drag/pitch 입력을 받는다.
특히 하단 시트의
뒤로가기/단계 변경 버튼은 시트가 접히며 같은 터치가 WebView 지도 탭으로 이어질 수
있으므로 pointer up/cancel 이후까지 외부 UI 입력으로 취급해 지역 선택 hit-test 와
분리한다.
지역/인물/시간순 reveal 이 긴 경우에는 지도 우측 중앙에 큰 반투명 `>>` 버튼을
띄운다. 이 버튼은 아이콘만 보이고 tooltip 으로 "핀 애니메이션 건너뛰기"를 제공하며,
탭하면 순차 핀 애니메이션을 멈추고 모든 사건 핀을 즉시 표시한 뒤 사건 목록 패널을
펼친다.
지도 안내 오버레이는 설명 캐릭터가 말해주는 채팅형 가이드 말풍선처럼 표현한다.
오버레이 바깥 배경은 현재 팔레트의 상단 버튼 배경색을 반투명하게 따르고, 상단 dismiss
배지는 현재 강조색, 본문 말풍선은 인물 역할색을 이전 역할색 비율에 가깝게 섞어
오렌지/청록 조합이 살아나게 한다. 대신 최종 alpha 를 낮춰 지도 위에 가볍게 얹힌
유리막처럼 보여야 한다. 텍스트와 안내 아이콘은 배경 투명도의 영향을 받지 않도록
완전한 흰색으로 고정한다.
반투명 오버레이 안에서 기본 안내 본문 왼쪽 원형 슬롯에
`assets/avatars_thumbs/guide.png` 를 중앙 기준 1.13배로 살짝 확대해 흰 여백이
도드라지지 않게 담는다. 원형 슬롯 지름은 기본 48px 이고, 홈 첫 안내에서만
70px 로 키워 캐릭터 표정이 더 잘 보이게 한다. 시대 선택 직후 권 목록과 보기
방식을 안내할 때는 이 PNG와 슬롯·간격을 모두 숨기고 말풍선이 해당 폭까지 사용한다.
그 오른쪽에는 별도 둥근 말풍선 안에 안내 문장을 배치한다. 상단에는
`화면 아무데나 누르면 사라집니다` 배지를 중앙 정렬로 표시한다. 배지와 안내 본문
사이는 한 줄 정도 더 띄워 말풍선이 답답해 보이지 않게 하고, 본문 문장에는
이모티콘이나 텍스트 그림자를 넣지 않는다. 첫 화면에서도 같은
오버레이로 "오늘은 성경 어디를 여행해볼까요?",
`시간 순·인물·장소` 선택 안내를 보여 주며, 시대 선택 전에는 `①`, `②`
원형 숫자 배지로 단계만 나눠 보여준다. `오늘` 탭 돋보기 구절 검색 안내는 `②` 아래
번호 없는 괄호 참고 줄로 배치해 번외 동선처럼 보이게 한다. 시대를
고른 뒤에는 안내가 사라지지 않고 선택한 시대와 권 이름 목록, 보기 방식 선택을
두 개의 불릿으로 간결하게 보여 준다. 첫 화면 제목은 좁은 폰에서도 한 줄을 유지하도록 축소 렌더링하고, 단계
문구는 줄마다 다른 크기로 줄어들지 않도록 같은 본문 크기를 유지한다.
모드 선택 뒤의 region/character/timeline 안내도 같은 캐릭터 가이드 형식으로
통일한다. 안내가 떠 있는 동안 지도·안내문·하단 시트 어디든 pointer down 이
들어오면 안내를 즉시 dismiss 한다. 오버레이가 덮은 지도 영역은 입력을 막지 않고
아래 MapLibre hit-test 로 전달해 첫 탭도 지역 선택이나 일반 지도 탭으로 동작하게
한다. 하단 시트의 버튼/스크롤은 힌트 dismiss 와 기존 동작을 함께 처리한다. 장소
선택 모드로 전환된 직후에는 같은 터치 누수를 막기 위한 짧은 suppression 만 남기고
후속 지역 탭은 빠르게 받을 수 있도록 suppression 을 정리한다.

### 3.5 앱 chrome 톤 색상

3D 지도 배경 자체는 유지하고, 앱 버튼·패널·카드·탭은 선택한 색 조합의 역할색을
따른다. `클래식`은 main 브랜치의 어두운 올리브 chrome, 베이지 패널, 골드 미션을
기준으로 하고, `네이비`는 홍보 이미지의 진한 네이비 잉크와 청록 수계 톤을
사용한다. `파스텔`은 파스텔 보라 primary 와 청록·오렌지·핑크 역할색을 나눠 써서 프로필
탭/카드/통계가 한 색으로 뭉치지 않게 한다. `다크`는 검은 지도 톤, 어두운
패널, 금빛 포인트를 써서 다크 테마처럼 보이게 한다. 사용자는 `오늘` 탭의 `테마`
시트에서 이 네 색 조합을 고를 수 있고 선택값은 `SharedPreferences`에 저장된다.
팝업, 홈 선택 시트, 프로필, 퀴즈, 성경 리더, 구절 검색, 알림 드롭다운/전체보기 같은
공통 화면은 `AppPaletteTheme`, `AppColors`, `AppSurfaces`, `SubPageScaffold`,
`ParchmentPageScaffold` 를 통해 같은 팔레트를 공유한다.
본문과 탭 비선택 텍스트는 `palette.text`/`palette.mutedText`를 우선하고,
밝은 고정 표면 위에 다크 팔레트의 밝은 글자를 얹지 않는다. 홈 상단 유틸리티
버튼, 선택 시트 배경/질감/핸들, 시대·인물·구간 선택 카드, 사건 카드, 프로필 요약
카드, 다이어리/통독 진행률 카드는 `AppPaletteTheme`의 표면·테두리·역할색을
따라 동시에 바뀐다. `다크`는 카드/패널 표면을 어둡게 유지하고 보조 텍스트를
밝혀, 같은 컴포넌트가 밝은 테마와 다크 테마 모두에서 읽히게 한다. 다크 팔레트의
프로필 흰색 쉘은 깊은 검정으로 바꾸고, 홈 하단 스크롤 패널은 거의 검정 표면으로
지도와 분리한다. 상세/미션처럼 읽기 중심인 표면은 팔레트 안의 밝은 표면 역할색을
써서 고정 크림색이 반복되지 않게 한다. 블랙 팔레트의
`primary`/`primaryDeep`은 아이콘과 보조 액션에 쓰이는 밝은 청록 계열이며, 구간 선택
패널은 자체 어두운 표면을 깔아 부모 시트 색과 섞이지 않게 한다.
홈 intro/시간순/장소 선택/장소 사건 목록 wrapper, 주간 미션의 금주 인물·지역 헤더와
사건 카드 row, 공지사항과 사용법 리스트, 프로필 설정 시트, 통독 진행률 페이지는
모두 `AppPaletteTheme` 표면을 사용해 `다크`에서 고정 크림색 표면이 남지 않게 한다.
완료 초록과 선택색이 겹쳐 보이지 않도록 사건 카드 선택 테두리는 팔레트 선택색,
완료 테두리는 더 낮은 채도의 초록을 쓴다.

### 4.4 Region Polygon — 장소로 보기 3D 지도 표현

장소 선택은 무료 3D 지도 위에서 "성경 세계의 지역을 고르는" 느낌을 유지한다.
후보 region 은 따뜻한 골드 계열, 선택 region 은 세이지 그린 계열로 MapLibre
GeoJSON fill/border layer 에서 직접 그린다. 이전 Flutter `CustomPainter` 기반
2D polygon overlay 는 제거됐고, polygon 시각·라벨·탭 hit-zone 은 모두
`StoryTerrain3dMap` 의 WebView 내부 layer 로 처리한다.

- **후보**: 시대를 켰을 때 사건이 있는 region 만 은은하게 떠오른다.
- **선택**: 특정 region 을 탭하면 선택 색과 라벨 강조로 후보들과 분리된다.
- **Hit-test**: `queryRenderedFeatures` 로 fill layer 를 먼저 조회하고, iOS
  WebView/terrain 조합에서 빠질 경우 화면 좌표를 위경도로 바꿔
  point-in-polygon 으로 다시 판정한다. 장소 선택 단계에서는 region 폴리곤
  hit 을 사건/랜드마크 hit 보다 먼저 처리해 영역 내부 어디를 눌러도 같은
  지역 선택으로 이어지게 한다.
- **라벨**: 장소 선택 단계의 region 라벨은 폴리곤 내부 중심점 근처에
  지도 지명보다 조금 큰 오커/골드 톤 단일 라벨로 표시해 국가명과 구분한다.
  큰 배지나 버튼형 장식 대신 작은 선택 점과 은은한 경계/채움으로 영역 전체가
  선택 가능하다는 affordance 를 준다. 한국어 국가/region 라벨은 기본 지도
  symbol layer 와 분리해 MapLibre expression 으로 줌에 맞춰 크기를 조정한다.
- **사건 핀 우선순위**: 감정이 새겨진 원형핀은 노란 오로라를 상시 표시해
  장소/인물 사건 목록에서도 이미 새긴 이야기가 눈에 띄게 한다. 감정 핀,
  현재 선택 핀, 이전/다음 전환 glow 대상, 감정 도장 대상은 DOM marker
  z-index 를 높여 다른 원형핀과 겹쳐도 숫자나 감정이 가려지지 않게 한다.
- **이전/다음 전환 카메라**: 사건 상세의 이전/다음 이야기 이동은 현재/목표
  핀을 하단 선택 패널 padding 이 반영된 `fitBounds` 로 더 넓게 잡아, 목표
  원형핀이 아래 스크롤 패널 뒤에 숨지 않게 한다. 이때 지도는 잠깐 보여 주는
  전환 애니메이션일 뿐 route history 가 아니므로, 목표 상세의 `<`는 지도
  대신 직전 상세로 돌아가야 한다. 프로필 카드에서 상세로 들어갈 때는 같은
  핀을 약 1초 pulse 로 보여 준 뒤 상세를 열고, 루트 `<`는 프로필로 돌아간다.

## 5. 인터랙션 패턴

### 5.1 시대 → 인물 → 이벤트 흐름

1. 구약/신약 토글 → 해당 시대 목록 표시
2. 시대 탭 선택 → 인물 목록 로드 + 지도 중심 이동
3. 인물 선택 (복수 가능) → 타임라인 병합 표시
4. 이벤트 카드 클릭 → 지도 핀 강조 + 상세 다이얼로그

1. 검색어 입력 (220ms 디바운스)
2. 결과 선택 → 시대/인물 자동 선택 + 이벤트 포커스
3. 지도 해당 위치로 이동

2. 성경 리더와 같은 가로 드롭다운 row 에서 신약/구약, 권, 장 선택 → 해당 장의 절 번호를 프로필 달력처럼 선으로 구분된 버튼 그리드로 표시. 선택된 절의 배경색은 셀 전체를 채우고, 세로 구분선은 오버레이로 그려 선택색과 선이 어긋나지 않게 한다
3. 절 버튼 선택 → 버튼 그리드 바로 아래에 `창 1:1` 같은 짧은 참조 pill 과 선택 구절 본문을 담은 말씀 카드 표시
4. `events_ordered.bible_refs` 범위에 해당 절이 포함된 이야기 검색
5. 결과는 항상 같은 row 에서 왼쪽 70% `StoryMapPanel` 지도와 오른쪽 30% `StoryEventThumbCard` 기반 1열 카드 스크롤 영역으로 표시한다. row 높이는 오른쪽 카드보다 조금 높은 정도로 제한한다. 오른쪽 열의 시대 구분 배지는 가변 폭으로 제한하고, `예수님의 공생애`·`포로 및 포로 후기`처럼 긴 시대명은 최대 두 줄로 중앙 정렬해 좁은 모바일 폭에서도 가로 오버플로가 나지 않게 한다. 큰 글자에서는 전체 시대명을 읽을 수 있도록 필요한 줄 수만큼 높이가 늘어난다.
6. 지도 핀 탭은 해당 이야기 위치를 강조하고, 카드 탭 → 홈의 기존 이야기 상세/본문 읽기/퀴즈/감정 새김 흐름으로 이동

### 5.2.2 매일/주간 미션 카드

1. `오늘` 탭은 현재 여정 필터에 포함된 이야기를 `원역사 → 족장 → 출애굽 → 사사 → 통일왕국 → 분열왕국 → 포로 및 포로 후기 → 예수님의 공생애 → 사도 → 후기 사도`와 각 시대의 `rankInEra` 순으로 고정한다. `역사의 종결`과 요한계시록 참조 사건은 공개 전까지 제외한다. 선택 범위에서 감정을 새기지 않은 첫 이야기를 오늘 이야기로 삼고, 전부 완료했으면 범위의 마지막 이야기를 유지한다. 카드 좌상단과 오늘 지도 핀은 DB의 시대 내부 번호를 노출하지 않고 이 선택 범위 전체에서 1부터 다시 매긴 같은 순번을 사용한다. 헤더 아래 여정 선택 바의 `>`는 오른쪽 끝 28px 원형 버튼으로 표시하고, 그 아래 선택 범위 진행 bar와 `완료/전체` 수를 함께 둔다. 별도의 날짜별 매일 미션 화면과 딥링크, `지도` 탭의 `미션` 버튼은 기존 날짜 시드를 유지한다.
2. 매일 미션은 상단 소개 영역에서 네비게이션 아이콘 + **오늘의 미션** 라벨을 먼저 보여 주고, 그 아래 시대 이모지+텍스트, 인물 avatar+텍스트, 핀 이모지+장소 텍스트로 오늘의 여정을 말한다. 이 소개 문장 안에는 별도 rounded chip 을 쓰지 않는다
3. 매일 미션은 소개 아래 본 미션 블록을 하나의 rounded rectangle 로 묶고, 맨 위에 나침반 이모지 + **오늘의 사건** 라벨을 둔다. 그 아래 "「사건명」 사건" 메인 버튼은 이모지나 선택 라벨 없이 가운데 정렬된 굵은 제목처럼 길게 배치하고, **인물 루트 / 장소 사건**은 `함께 보기` 보조 버튼 row 로 분리한다. 오늘 사건은 항상 핵심 CTA 이고, 인물 루트와 장소 사건은 오늘 사건을 입체적으로 보는 보조 탐색이다. 장소 사건은 1개만 있어도 눌러 볼 수 있으며 사건 수를 그대로 표시한다
4. 매일 미션 본 블록은 버튼 row 아래 지도를 충분히 확보하고, 필요하면 구분선과 사건 카드 row 는 세로 스크롤 아래에서 이어 보여 준다. 인물 루트 지도에서는 인물 코드 legend 를 숨긴다. 같은 사건에 오늘 KST 감정을 새겼으면 축복 문구를, 이전 날짜 감정만 있으면 다시 미션 문구를 구분선과 사건 카드 row 사이에 표시한다. 감정 기록이 없거나 인물/장소 보조 보기에서는 추가 문구를 숨긴다
5. 매일·주간 미션의 사건 카드는 설명을 숨기고 제목을 한 줄 수동 가로 스크롤로 표시하며, 우측 끝의 강한 흐림으로 더 볼 수 있음을 알린다. 주간 미션은 인물/지역 헤더와 지도, 사건 카드 row 만 보여 주며 매일 미션 전용 다시 미션/축복 문구를 쓰지 않는다
6. 주간 미션 헤더와 사건 카드 row 배경은 현재 팔레트 표면을 따른다. `다크`에서는 `cardSurface`/`panelSurface` 계열의 어두운 표면을 쓰고, 진행률 카드와 금주 헤더 사이에는 별도 여백을 둔다. 진행률 카드는 고정 높이를 두지 않아 아주 큰 글자에서도 내용만큼 확장한다.

### 5.3 학습 완료

1. 이야기 상세 → 본문 읽기 + 퀴즈 시작 (4번 보기는 항상 "헷갈렸어요"). 본문 읽기는 사건에 연결된 절만 성경 리더에서 보여 주며, 여러 본문이면 **다음**으로 이동하고 마지막 **읽기 완료** 버튼을 눌러야 완료된다. 뒤로가기(`<`)로 나가면 읽음 처리하지 않는다
2. 각 문항에서 정답 확인 → 즉시 정답/오답/헷갈림 + 해설 표시 → 다음 문항 이동. 마지막 전체 리뷰를 확인하면 정답/오답/헷갈림을 `user_quiz_attempts`에 저장
3. 본문 읽기와 퀴즈가 모두 완료되면 **지도 위에 새기기** 버튼 활성화
4. 단일 팝업 위쪽의 `감정 선택` 바로 옆에 `필수`, 아래쪽의 `코멘트` 바로 옆에 `선택사항` 라벨을 붙인다. 필수 감정 8개 중 하나만 골라도 저장할 수 있으며, 선택 코멘트는 최대 100자로 입력하고 입력칸은 한 줄부터 입력에 맞춰 실시간으로 늘어나며 최대 5줄까지 보인다. 키보드가 올라오면 감정·코멘트 본문만 줄여 스크롤하고, 하단 `새기기`는 둥근 팝업 표면 안에 고정해 항상 탭할 수 있게 한다
5. 읽기+퀴즈+감정 새김이 모두 끝났을 때 `user_event_progress.is_completed=true` 저장, 도장 문구는 "완료" 대신 선택 감정 심볼. 감정 새김 버튼은 코멘트가 있으면 `감정 - 코멘트`, 없으면 `감정`만 표시하고 "완료 취소" 시 감정 row를 삭제해 지도/카드 이모지를 제거한다
6. `notify_quiz_completed` RPC 호출 → 본인 인앱 bell 에 퀴즈 완료 알림 표시
7. 퀴즈 버튼은 `정답 N · 오답 N · 헷갈림 N` 으로 표시하고 정답 0개=빨강, 일부 정답=주황, 모두 정답=초록으로 상태를 보여 준다
8. 지도 번호 핀은 숫자 중심을 유지하고 작은 컬러 감정 이모지 배지를 붙인다. 하단 사건 카드는 감정 새김이 있으면 좌상단 배지를 컬러 감정 이모지로 바꾸고, 우측 하단 작은 초록 원에 이야기 순번을 표시한다
9. 감정 저장 직후 상세 페이지를 잠시 닫아 진입 출처의 지도에서 핀/카드 변화를 먼저 보여 주고, 0.5초 뒤 해당 사건 핀에 감정 도장을 재생한 다음 도장 완료 후 1초 뒤 같은 상세로 복귀한다. `오늘`의 현재 이야기에서 들어온 상세는 공유 지도를 `오늘` 표현으로 유지하고 도장 대상 사건을 애니메이션 동안 현재 위치에 고정하며, 복귀한 상세의 `<`는 `오늘`로 돌아간다. `지도`에서 필터링한 사건 상세는 기존 지도 필터를 복원해 그 위에서 도장을 재생하고 `<`는 `지도`로 돌아간다. 프로필 나의 다이어리처럼 지도 준비를 건너뛰고 상세에 들어온 경로에서는 기존 지도 준비 흐름을 사용한다. 지도 위 감정 도장 및 이전/다음 이야기 전환 애니메이션은 내부 재진입 가드로 중복 실행을 막고, 도장 재생 중에는 전체 홈 입력과 시스템 뒤로가기를 잠근다. 이전/다음 이야기 전환으로 잠깐 보이는 지도는 history가 아니며, 새 상세의 `<`는 직전 상세를 우선 열고 직전 상세가 없으면 원래 진입점으로 돌아간다. 평상시 지도·패널 터치는 차단하지 않는다
10. `내정보` 헤더는 별도 제목 없이 수정 가능한 34px 프로필 사진·15px 닉네임을 바로 보여 주고, 오른쪽에 공지/알림/설정 아이콘을 둔다. 진행 본문은 음영이 있는 독립 `이야기 탐험 요약`, 118px 최소 높이에서 하단 액션만큼 확장하는 `다이어리`·`통독 진행률` 카드, 테두리 없이 그림자로 구분한 독립 `다이어리` 순서다. 두 진행 카드 하단에는 각각 `기록하기`·`이어읽기`를 두고 큰 글자에서는 내용만큼 확장한다. 요약의 `완료`를 누르면 제목이 `완료`인 전체/완료/미완료 필터 페이지를 연다. 내부 달력과 선택 날짜 기록 카드의 테두리는 유지한다. `복습` 페이지는 감정 카테고리와 복습 항목을 독립 카드로 구분하고, 양쪽 모두 필터 아래 구분선과 요약 없는 공용 2열 카드를 인라인으로 표시한다. 완료·저장한 이야기·찾기 결과도 같은 표현을 쓰며, 썸네일은 기존 정사각형의 절반 지름 원형으로 줄이고 제목·장소·등장인물은 각각 한 줄 수동 가로 스크롤과 강한 우측 흐림을 사용한다. 다이어리 달력의 감정·통독·다이어리 활동은 날짜 아래 한 줄의 원형 배지로 표시하고, 세 활동을 모두 마친 날은 1.5배 큰 초록색 채움 원 안의 흰 체크 하나로 합친다.
11. `이야기 탐험 요약`의 `저장한 말씀` 카드는 전체 저장 말씀 화면과 같은 `SavedVerseRow` 기반 `SavedVersesScreen`으로 이동한다. 다이어리 전체보기는 이번 달 기록일·연속일 통계, `전체`·`이번 달` 필터, 날짜별 2줄 미리보기만 사용하고 북마크/최근 필터와 플로팅 작성 버튼은 두지 않는다. 저장한 성경 구절 전체보기와 다이어리 전체보기는 상단에 아이콘형 이전 버튼과 화면 제목을 같은 row로 배치하고, 본문 카드는 버튼 폭에 밀리지 않도록 좌우 전체 폭을 사용한다
12. `SavedVerseRow`는 왼쪽 본문/코멘트 컬럼과 오른쪽 삭제 아이콘 컬럼으로 구성한다. 왼쪽 첫 줄은 작은 초록 원 참조 배지와 전체 구절 본문을 함께 보여 주고, 저장한 말씀은 아래 구분선 뒤 묵상 코멘트 또는 회색 빈 코멘트 안내를 표시한다. 하이라이트만 지정한 말씀은 코멘트 영역을 숨기고 row 배경을 선택한 파랑/노랑 형광색으로 칠한다
13. 프로필의 `다이어리`는 한국 시간 기준 월 달력과 이전/다음 월 이동을 제공한다. 날짜 셀은 얇은 구분선만 사용하고 오늘은 날짜 숫자 동그라미, 선택 날짜는 은은한 배경으로 구분한다. 기록이 없는 선택 날짜에는 `오늘`·`성경`·`지도` 각각의 앞에 루트 네비게이션과 같은 아이콘을 놓고 `탭으로 이동하여 기록을 남겨보세요`를 이어 표시한다. 다이어리 작성·수정은 전용 페이지를 사용한다. 통독 진행률의 완료 장 배경은 셀 왼쪽·위쪽 테두리에서 3px 안으로 들어오게 한다.
14. 게이미피케이션(score/xp) 없음 — 완료 플래그만 기록 (ADR 참조)

성경·내정보 루트 탭이 공유 지도 위에 표시되는 동안에는 지도 WebView를 트리에서 제거하지 않되 MapLibre 제스처 핸들러를 끈다. 성경 본문 스크롤과 내정보 당겨서 새로고침은 뒤쪽 지도의 이동·확대·회전에 영향을 주지 않아야 하며, `오늘`·`지도`로 돌아온 뒤에만 지도 제스처를 다시 활성화한다.

### 5.4 비로그인 로그인 유도

1. 사용자별 저장이 필요한 액션은 비로그인 상태에서 즉시 3초 스낵바를 띄우고 우측에 **이동** 액션을 둔다. **이동**은 `내정보` 탭의 인라인 로그인 카드로 진입한다.
2. 인라인 로그인 카드는 카카오/Google/Apple 소셜 로그인만 제공한다. 모바일 OAuth는 앱 바깥 기본 브라우저가 아니라 인앱 브라우저/Safari View Controller 계열 launch mode를 사용한다. Google 재로그인은 이전 계정으로 바로 들어가지 않도록 계정 선택 화면을 요청한다.
3. 스낵바 적용 대상: 성경 구절 저장/하이라이트, 성경 화면 우측 상단 저장 말씀 버튼, 이야기 저장, 감정 새김.
4. 사건 상세의 **읽기**와 **퀴즈 시작**은 공용 로그인 팝업을 연다. 팝업은 `내정보 화면에서 로그인한 뒤 다시 이용해 주세요.` 문구와 **내정보로 이동** 버튼을 사용하고, 확인하면 `내정보` 탭의 인라인 로그인 화면으로 전환한다. `내정보`의 다이어리/통독 카드는 비로그인 미리보기 영역 안에서 입력을 차단한다.
5. 매일/주간 미션 목록과 일반 성경 읽기는 비로그인도 열 수 있지만, 로그인 전에는 사건 상세 읽기·퀴즈나 사용자별 저장 액션을 시작하지 않는다.

### 5.5 알림 (Bell)

1. 프로필 헤더의 🔔 아이콘 클릭 → 드롭다운 오픈 (미독 최대 5개)
2. 알림 탭 → `mark_notification_read` RPC + deep link 라우팅
   (`/proposal/<id>`, `/event/<id>`, `/weekly` 중 하나)
3. 모바일/태블릿에서 제안 관련 알림 탭 → "컴퓨터에서 확인하세요" 다이얼로그
4. "모두 읽음" → count/list/history provider 를 함께 invalidate 해 빨간 `!` 배지와 "새로운 알림이 없어요" 빈 상태를 즉시 반영
5. "전체 보기" → `NotificationHistoryScreen` (최근 30일, 읽은 것 포함)
6. 드롭다운은 최대 340px 폭을 사용하고, 더 좁은 화면에서는 좌우 8px 여백 안에 맞춰 폭과 위치를 함께 줄인다.

### 5.6 공지사항과 사용법

1. 프로필 헤더의 📣 아이콘 클릭 → `AppPublicationsScreen`.
2. 게시물은 프로필 다이어리 전체보기처럼 제목과 본문 일부가 보이는 리스트로 표시한다.
3. 항목 탭 → `ParchmentDialog` 상세 팝업에서 전체 본문을 보여 주고, 본문 URL 줄 또는 `link_url`은 자동 링크 줄로 렌더링한다.
4. URL 줄은 `url_launcher`로 브라우저를 열어 개발자가 게시한 가이드 문서로 이동한다. 별도 링크 액션 버튼은 두지 않는다.
5. 목록 본문의 가장 밖 표면은 테두리 없이 음영을 유지하고, 공지 사이 구분선은 두지 않는다. 리스트 카드와 상세 팝업은 현재 팔레트 표면과 글자색을 사용한다. 블랙 팔레트에서는 카드 배경을 `cardSurface`로 유지한다.
6. `개인정보 보호` 페이지와 계정 삭제 확인 팝업도 가장 밖 표면의 테두리를 제거하고 음영은 유지한다. 내부 정보 카드·입력란 테두리는 유지한다.

## 6. 접근성

### 글자 크기와 지도 설명

`오늘` 탭 상단의 `테마`와 `큰글자` 버튼은 같은 `FontScaleBottomSheet`를 섹션별로 연다. `테마`는 색 조합 4개(`클래식`/`네이비`/`파스텔`/`다크`)만 보여 주며 새 설치 기본값은 `네이비`다. `큰글자`는 성경 구절 미리보기와 3단계(작게 1.0x / 보통 1.2x / 크게 1.4x)만 보여 주며 새 설치 기본값은 `보통`이다. 선택은 즉시 전역 테마/`MediaQuery.textScaler`와 `SharedPreferences`에 반영된다. 핵심 텍스트는 큰 글자에서도 줄바꿈·가변 높이·내부 스크롤로 읽을 수 있어야 한다. 단, 이야기 상세 장면 카드 앞면 캡션은 이미지를 가리지 않도록 한 줄 말줄임표로 고정하고 전체 문장은 뒷면에서 제공한다.

글자 크기 선택 카드의 세 라벨은 모두 같은 한 줄 축소 영역을 사용해 `크게`를 선택한 상태에서도 줄바꿈이나 수직 위치 차이가 생기지 않게 한다.
